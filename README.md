# ☕ Coffee Sales Dashboard

## 1. Project Title

*Coffee Sales Dashboard*

An interactive Microsoft Excel dashboard created to analyze coffee sales and provide useful business insights.

---

## 2. Project Description

This project analyzes coffee sales data and presents important business information in an easy-to-understand dashboard.

The raw dataset was obtained from *Kaggle* and cleaned in Microsoft Excel before creating the dashboard. Data cleaning included removing duplicate records, fixing date formats, separating dates into day, month, and year, calculating total sales, and using *XLOOKUP* to retrieve related information.

After preparing the data, Pivot Tables, Pivot Charts, and Slicers were used to build an interactive dashboard for analyzing coffee sales trends.
